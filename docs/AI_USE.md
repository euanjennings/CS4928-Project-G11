## Where AI output was wrong or overruled

- Claude's 20 Oct corrected drafts were not applied; the frozen preregistration was kept (20 Oct row).
- Claude's proposed semantic field label was not adopted as primary (4 Nov Claude row).
- The ChatGPT-drafted extractor had v1 bugs, and even after fixes it failed equivalence validation (4 Nov ChatGPT row).
- Claude's first description of the moved methods omitted `publicizeResources` and `getAndroidFrameworkResourcesAsStream`; corrected against the ground-truth list before commit.
- Claude's README draft said "other CK metrics unchanged" (fields and LOC changed), and §6 overclaimed acyclicity and further extraction; Sean's Codex-assisted review caught both ([PR #6](https://github.com/euanjennings/CS4928-Project-G11/pull/6)).
- Claude's first harness version dropped modified files from its source hashes; caught by a dry run before hand-over.
- The harness README called the new test a check of the null branch; Cian's Claude Code review found the branch unreachable.
- Claude's synthesis draft listed three CK changes instead of six and treated #3124's `ResourcesDecoder` as a new extraction (it is a rename of `AndrolibResources`); a ChatGPT review caught both, and each was verified against the data before correction.
